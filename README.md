# Font Atlas Library | کتابخانه فونت

کتابخانه مستقل برای مشاهده و جست‌وجوی منابع فونت‌های فارسی، عربی و لاتین.

## وضعیت
- سایت HTML/CSS/JavaScript به مخزن منتقل شده است.
- فهرست شامل **۱۲۱ مدخل اولیه** و پیوند به منابع رسمی است.
- **هیچ فایل واقعی فونت هنوز در مخزن آپلود نشده است.**
- مجوز استفاده تجاری یا بازتوزیع هر فونت باید در منبع اصلی بررسی شود.
- مخزن فعلاً **private** است؛ برای عمومی‌سازی یا فعال‌سازی انتشار عمومی تأیید جداگانه لازم است.

## اجرا
فایل `index.html` را باز کنید. `app.js` کاتالوگ و جست‌وجو را ایجاد می‌کند.
